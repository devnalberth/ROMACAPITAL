# Referências do template

Esta pasta preserva as variações originais de página inicial para consulta visual durante o desenvolvimento da Roma Capital.

## Mapeamento

- `index.html` — página principal original do template;
- `index-2.html` a `index-7.html` — variações originais 2 a 7;
- `index-9.html` a `index-12.html` — variações originais 9 a 12.

A antiga `index-8.html` foi escolhida como base do projeto e promovida para `/index.html`.

> Estas páginas são referências internas. Não fazem parte da navegação pública do site final.
